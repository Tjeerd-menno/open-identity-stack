# Administration overview

This section covers the tasks administrators perform inside OpenIdentityStack after the platform is running.

## Administrator tasks

- manage users and access
- assign roles and permissions
- organize delegated administration through groups
- register clients and redirect URIs
- create and rotate service account credentials
- manage external identity providers
- monitor and revoke sessions
