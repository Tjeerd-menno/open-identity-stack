# Getting started

OpenIdentityStack is aimed at teams that want a secure, maintainable identity layer for
web and API products.

## What you get

- sign-in, sign-up, and role management with OpenIddict
- support for OAuth 2.0 and OpenID Connect flows
- reusable client and service account management
- delegated administration and permission boundaries
- external identity provider federation
- certificate-backed token signing and encryption
- an admin web UI for day-to-day identity operations

## Who this page is for

You should be reading this site if you are:

- evaluating whether to adopt OpenIdentityStack
- planning a local or production deployment
- preparing an operational runbook for your team

If you are writing application code, use the API and domain references in
the [Reference section](../reference/index.md).
