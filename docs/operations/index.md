# Operations overview

This section is for the team that keeps OpenIdentityStack healthy after the first deployment goes live.

## Day-2 responsibilities

Operators should have a runbook for:

- health and startup verification
- database migrations and restores
- certificate rotation
- admin account bootstrap and recovery
- upgrade sequencing
- incident triage for login, proxy, or token problems
